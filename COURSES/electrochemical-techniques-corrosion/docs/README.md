# Electrochemical Techniques in Corrosion Science and Engineering

## العربية
موقع مقرر جامعي ثنائي اللغة يعمل محلياً دون خادم. افتح `index.html` في متصفح حديث، واستخدم زر اللغة للتحويل إلى العربية واتجاه RTL.

## English
This is a self-contained bilingual static course website. Open `index.html` in a modern browser. No build step or internet connection is required.

### Contents
- 14 complete course modules with explanations, equations, worked examples, laboratories, cases, quizzes and feedback.
- Interactive reference conversion, Faraday, LPR, RDE, EIS and mixed-potential tools.
- Assessment plan, ILO alignment, benchmarking, source inventory, visual manifest and QA documentation.
- Original SVG explanatory figures; no fabricated experimental data.

### Administrative status
Course code, credits, institutional ownership, instructor and formal ILO approval are provisional and require institutional verification.

### Source basis
Primary: Kelly et al. (2003). Supporting: Marcus & Mansfeld (2006) and Dornbusch (2019), plus documented standards and selected recent research.
