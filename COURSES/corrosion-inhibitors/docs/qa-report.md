# Quality-Assurance Report

## Academic completeness

- Twelve modules cover the full planned inhibitor sequence.
- Every module includes outcomes, connected explanation, concepts, equations, a worked example, misconception correction, activity, quiz, and source basis.
- Quantitative and design content progresses from efficiency calculations to complete management design.

## Bilingual quality

- Core instructional content is available in Arabic and English.
- Language modes support bilingual, English-only, and Arabic-only views.
- Arabic-only mode uses RTL layout.

## Accessibility

- Semantic landmarks and heading hierarchy.
- Skip link, keyboard-operable controls, visible focus, scalable text, high-contrast option.
- Reduced-motion support, alt text, captions, accessible form labels, live feedback.
- Responsive tables and print stylesheet.

## Technical checks

- Static HTML/CSS/JavaScript; no server, framework, tracking, or advertising.
- Stable anchor links for major sections and modules.
- Search, completion progress, bookmarks, quizzes, calculators, simulator, print, and browser PDF.
- Local storage only; no transmitted student data.

## Limitations

- Page-level textbook citations require completion for formal publication.
- No external licensed scientific photographs or microscopy are embedded.
- Institutional and regulatory details remain provisional.
- Interactive simulator is conceptual, not a validated research model.
