# Quantum Mechanics / ميكانيكا الكم — complete bilingual university course

Open `index.html` in a modern browser. The site is a static, self-contained teaching environment with 16 detailed chapters, English/Arabic switching, cited textbook figures, original scientific graphs, interactive model explorers, worked examples, mastery feedback, assessment guidance and computational laboratories.

## Suggested deployment

You may open the file directly, or serve the directory locally:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## Academic status

Administrative values such as course code, credits, programme, instructor and institution are **Provisional — institutional verification required.** The academic content is synthesized from the uploaded authorized texts; reproduced figures include source/page/figure attribution. External official sources are used for international benchmarking and current CODATA constants.

## Key files

- `index.html` — complete course website
- `reports/source_inventory.csv` — source governance
- `reports/topic_source_coverage_matrix.csv` — per-topic evidence coverage
- `reports/visual_asset_manifest.csv` — figure attribution and rights basis
- `reports/assessment_plan.csv` — 100% assessment plan
- `reports/ilo_alignment_matrix.csv` — ILO mapping
- `labs/` — four Python computational laboratories
