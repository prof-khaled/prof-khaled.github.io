# Technical documentation

The course is a static site. Open `index.html` directly or serve the folder with any static web server. No build step is required.

- `index.html`: all course chapters, assessment, sources and formula sheet.
- `css/styles.css`: responsive/print/RTL styling.
- `js/app.js`: language toggle, local progress/bookmarks, search and two canvas parameter explorers.
- `assets/figures/`: reproduced uploaded figures and original educational figures/graphs.
- `assets/covers/`: source-cover thumbnails extracted from uploaded PDFs.
- `labs/`: Python computational laboratories.
- `reports/`: source, topic, visual, assessment and ILO governance records.

For institutional deployment, host the entire folder so relative asset paths remain intact.
