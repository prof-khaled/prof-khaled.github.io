# Academic and technical quality-assurance report

## Academic checks
- The primary textbook controls the conceptual sequence.
- All major electrochemical techniques in the uploaded electrochemical chapters are represented.
- Equations include symbols, units or validity conditions where central.
- Each module contains explanatory prose, a scientific visual, worked example, activity, case, misconceptions, summary and formative feedback.
- Standards and recent articles supplement rather than replace uploaded sources.

## Integrity checks
- No artificial microscopy, failure photography or experimental dataset is presented as real.
- Original SVGs are explicitly labelled explanatory.
- Calculators display idealized outputs and warnings.
- Administrative assumptions are labelled provisional.

## Technical checks
- Relative links only; site works offline.
- All referenced figures, CSS, JavaScript and evidence files exist.
- HTML parsed without fatal structural errors.
- Responsive and print layouts provided.

## Items for institutional review
Course code, credits, contact/independent hours, prerequisites, assessment weights, instructor, institution, laboratory risk assessments and formal accreditation mapping.
