# Physical Chemistry / الكيمياء الفيزيائية — Complete Bilingual Course Website

## Open
Open `index.html` in a modern browser. For normal local hosting, run from this folder:

```bash
python -m http.server 8000
```

Then browse to `http://localhost:8000/`.

## Included
- 20 fully developed bilingual chapters following Chang & Thoman [1].
- 83 equation cards with symbols, units, assumptions, validity notes, and source/page citations.
- 20 original scientific graphs/schematics plus 3 interactive parameter explorers, with captions/accessibility text, interpretation, source credits, and plot CSV data when relevant.
- Worked examples, guided examples, independent exercises, laboratory/computational activities, case studies, applications, misconceptions, exam errors, revision sheets, and mastery checks.
- Chapter search, bookmarks, local progress, Arabic/English RTL/LTR toggle, mobile layout, print/PDF support.
- 30-week plan, 100% assessment strategy, rubrics, ILO alignment, mock exam, formula index, visual catalogue, source governance and APA-style numbered references.
- Supporting evidence files in `reports/`.

## Hosting
Upload the entire folder unchanged to GitHub Pages, Netlify, an institutional static server, or another static host. No backend is required.

## Source & visual policy
The primary instructional source is Chang & Thoman (2014) [1]; supporting attached textbooks are [2–7]. Official university pages [8–13] are curriculum benchmarks. The build reproduces no third-party external figures; all course visuals are original calculations, schematics, or interactive parameter explorers derived from cited scientific relationships.

## Provisional items
Course code, credits, institution, instructor, contact hours, local grading rules, approved accessibility arrangements, and responsible-AI wording require institutional verification before formal adoption.
