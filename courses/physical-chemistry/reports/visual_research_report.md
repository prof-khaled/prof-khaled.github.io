# Visual Research Report

The master prompt requires explanatory, scientifically accurate, cited and legally usable visuals. This build intentionally reproduces **no external third-party image**. Instead, each of the 20 chapters contains one original course graph or schematic based on the scientific relationships in Chang & Thoman [1]. Three chapters also contain original interactive parameter explorers.

- Numerical graphs are generated from theoretical equations and are labelled calculated/theoretical, never measured data.
- Conceptual schematics are labelled conceptual/original.
- CSV plot values are supplied where useful.
- Every static and interactive visual has bilingual explanatory text, source page range, accessibility text/readout, and a manifest entry.
- All assets are marked **Verified for use** because they were created for this course build.

Future external images must undergo independent creator/repository/licence/version/local-hosting/derivative-use verification before inclusion.
