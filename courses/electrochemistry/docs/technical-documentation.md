# Technical Documentation / التوثيق التقني

## Structure
- `index.html`: complete website.
- `assets/styles.css`: responsive, print, accessibility, bilingual, and component styling.
- `assets/app.js`: language, navigation, search, local progress, quizzes, calculators, and graph simulation.
- `assets/images/`: original SVG figures.
- `docs/`: curriculum and governance evidence.
- `data/site-manifest.json`: machine-readable inventory.

## Hosting
Open `index.html` directly or upload the directory to any static host. No build step or server is required.

## Maintenance
1. Preserve stable module IDs and reference numbers when editing.
2. Add every new visual to the manifest before publication.
3. Validate equations and calculators independently.
4. Re-run keyboard, mobile, RTL, print, link, and console tests.
5. Recheck external benchmark information annually.

## Privacy
Progress and bookmarks use browser `localStorage`. No student data leave the device.
