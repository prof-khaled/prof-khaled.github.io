# Electrochemistry / الكيمياء الكهروكيميائية

Complete bilingual university course website based on the uploaded master prompt and electrochemistry texts.

## Open
- Double-click `index.html`, or serve the folder with any static web server.
- Use the `ع | EN` selector for bilingual, English, or Arabic view.
- Print or choose browser **Save as PDF**.

## Contents
Fifteen modules, ten laboratories, interactive calculators and graphs, quizzes, weekly plan, assessment, rubrics, formula sheet, glossary, sources, visual manifest, assumptions, quality assurance, and technical documentation.

## Editing
Edit `index.html`, `assets/styles.css`, and `assets/app.js` directly with a text or code editor. Keep stable section IDs, reference numbers, and visual-manifest entries. The website has no external runtime dependency, tracking, or server requirement.

## Institutional release
Verify course metadata, local learning outcomes, laboratory SOPs, equipment, safety, waste, accessibility, assessment regulations, and software calculations before formal use.
