# General Chemistry — 23-Chapter Bilingual Course Website

## Open

Open `index.html` in any modern browser. No installation or internet connection is required for the course itself.

## Host

Upload the complete folder to any static host, including GitHub Pages. Keep `index.html`, `data/`, and `docs/` together. The page itself contains all runtime visual and code assets.

## Study controls

Use `ع | EN` for language, `◐` for theme, `⎙` for print/Save as PDF, the chapter sidebar for navigation, and the completion button at the end of each chapter. Progress and bookmarks are stored only in the current browser.
