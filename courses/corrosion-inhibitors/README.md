# Corrosion Inhibitors / مثبطات التآكل

A complete static bilingual university course website.

## Open locally

1. Unzip the package.
2. Open `index.html` in a modern browser.
3. For the most reliable local navigation, run a local server from the folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Hosting

The folder can be uploaded unchanged to GitHub Pages, Netlify, an LMS static-content area, or any ordinary web server. No build process, database, tracking, or server-side code is required.

## Editing

- Main content: `index.html`
- Visual design: `assets/styles.css`
- Search, quizzes, calculators, progress, and simulator: `assets/app.js`
- Original diagrams: `assets/images/`
- Governance and quality documents: `docs/`

## Data and privacy

Module completion and bookmarks use browser `localStorage` only. No student data are transmitted.

## Institutional verification

Before formal publication, verify the institution, instructor, course code, prerequisite policy, grading rules, accessibility arrangements, laboratory procedures, current regulations, supplier information, SDS data, and page-level source citations.
