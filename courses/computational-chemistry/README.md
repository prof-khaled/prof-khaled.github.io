# Computational Chemistry / الكيمياء الحاسوبية

A self-contained bilingual university course website built from the supplied master prompt and uploaded computational-chemistry resources.

## Open the course

Open `index.html` in a modern browser. No server, build step, tracking service or external JavaScript framework is required.

## Main features

- 16 detailed English/Arabic modules.
- Equations with purpose, symbols/units, assumptions and limitations.
- Textbook artwork reproduced from uploaded course materials with page/figure attribution.
- Original conceptual diagrams, worked examples, practical activities and mastery checks.
- Interactive theoretical Lennard–Jones explorer.
- Search, bilingual RTL/LTR switch, local progress/bookmarks, responsive layout and print/PDF mode.
- 16-week plan, 100% assessment strategy, formula sheet, exam centre and capstone rubric.
- Source inventory, topic-source matrix, visual manifest, ILO alignment and QA report.

## Directory structure

- `index.html` — complete course website.
- `css/styles.css` — responsive/print/accessibility styles.
- `js/app.js` — language switch, search, progress/bookmarks and theoretical LJ explorer.
- `assets/figures/` — verified textbook crops and original course illustrations.
- `assets/covers/` — source cover thumbnails for the course source catalogue.
- `labs/` — transparent Python teaching models (PES/Morse, MD/MC, Hückel, toy SCF).
- `data/` — benchmark and provenance templates.
- `reports/` — governance, coverage, assessment, ILO, visual and QA evidence.

## Important source/copyright note

The course master prompt supplied by the user explicitly authorizes use, reproduction, translation, adaptation, annotation and redrawing of uploaded course materials with attribution. Reproduced figures are identified in their captions and in `reports/visual_asset_manifest.csv`. This authorization applies to the uploaded resources, not arbitrary internet images.

## Institutional verification

Institution name, programme ownership, official course code, instructor, approved credit/contact hours, software licences, computing-resource policy, accessibility accommodations, academic-integrity policy and responsible-AI rules are provisional and must be verified locally before formal deployment.

## Editing

The website is intentionally framework-free. Edit `index.html`, `css/styles.css`, or `js/app.js` directly. If replacing a visual, update both its caption/alt text and `reports/visual_asset_manifest.csv`.
