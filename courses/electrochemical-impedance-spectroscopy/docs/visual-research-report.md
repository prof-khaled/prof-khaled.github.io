# Visual Research Report

## Strategy
The course uses original vector diagrams and equation-generated interactive graphs rather than reproducing publisher figures. This avoids uncertain external-image licensing while preserving the scientific relationships documented in the uploaded sources.

## Visual decisions
- Fundamental experiment: original cell, potentiostat/FRA, excitation and response diagram.
- Complex plane: original phasor diagram with rectangular and polar quantities.
- Ideal elements: original R, C, L symbols with exact equations and phase.
- Randles model: original circuit and process mapping.
- Frequency map: original conceptual frequency/time-scale diagram.
- Validation workflow: original linearity–stability–causality–KK–fit sequence.
- Fitting workflow: original hypothesis–CNLS–residual–evidence cycle.
- Applications map: original multidisciplinary concept map.
- Nyquist and Bode graphs: browser-generated from explicitly stated equations and parameters; labeled educational simulation.

No visual is presented as measured data. No external stock image, screenshot, or copied search-result image is used.
