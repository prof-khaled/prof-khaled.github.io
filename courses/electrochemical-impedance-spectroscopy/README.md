# Electrochemical Impedance Spectroscopy — Bilingual Course Website

## Open
- Open `index.html` in a current browser.
- The site works without a server or internet connection.
- `eis_course_standalone.html` is a single-file version.

## Features
- 12 complete Arabic–English modules.
- Search, language switch, RTL/LTR, progress, bookmarks, quizzes, print/PDF.
- Interactive Nyquist/Bode simulator, CSV workbench, and calculators.
- 15-week plan, 7 laboratories, assessment, rubrics, mock questions, formula sheet, and glossary.
- Source inventory, coverage matrix, benchmarking, visual manifest, assumptions, QA, and technical documentation.

## Hosting
Upload the folder contents to any static host. For GitHub Pages, place the contents in the repository root or `/docs` and enable Pages.

## Maintenance
- Recheck benchmark URLs and institutional metadata before publication.
- Validate local laboratory procedures and software conventions.
- Update the source inventory and visual manifest whenever material is added.
- Do not add external images without verified reuse permission.

## Safety
This course does not replace institutional laboratory SOPs, equipment manuals, safety data sheets, battery/gas/chemical procedures, or biological approvals.
