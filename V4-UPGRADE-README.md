# Prof. Khaled Academic Platform V4

## Included in this build
- Complete preservation of the uploaded website resources.
- Redesigned bilingual homepage.
- Shared V4 visual enhancement layer for every page.
- Sticky navigation, reading progress, dark mode, global search, and back-to-top control.
- New Knowledge Hub and Collaboration pages.
- Search index, sitemap, robots.txt, and responsive improvements.

## Deployment
Upload all files and folders in this directory to the existing GitHub Pages repository root. Keep the folder structure unchanged.

## Important
Google Scholar metrics on the homepage reflect the values previously supplied in the project. Update them when the academic profile changes.
