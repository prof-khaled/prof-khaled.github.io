# GitHub Pages Deployment Guide — V17

1. Keep a backup of the current deployed version.
2. Upload the complete contents of this V17 directory to the GitHub Pages publishing branch/folder.
3. Preserve `.nojekyll`.
4. In GitHub Settings → Pages, verify the correct source branch/folder and enforce HTTPS.
5. After deployment, test `academic-courses.html`, `ai-course-assistance.html`, all nine course URLs, and all NotebookLM buttons.
6. NotebookLM visibility depends on notebook sharing permissions; the website does not and must not store Google credentials.
