Installation:
1. Back up the existing website folder.
2. Copy all files and folders from this package into the website root.
3. Preserve the folder structure.
4. Open index.html and check the Services menu.
5. Open 10-scientific-services-training.html and test English/Arabic, the mobile menu, request form and WhatsApp contact form.
6. For local testing, use VS Code Live Server or: python -m http.server 8000
